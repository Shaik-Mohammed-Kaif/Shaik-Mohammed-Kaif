# GitHub Profile Assets — Setup Guide

This package is designed for the repository:

`https://github.com/Shaik-Mohammed-Kaif`

## Package contents

- `assets/banner.svg` — custom profile header
- `assets/typing.gif` — animated role strip
- `assets/welcome.gif` — animated data dashboard illustration
- `assets/tech-stack.svg` — grouped technology stack graphic
- `assets/divider.svg` and `assets/footer.svg` — matching decoration
- `assets/*-stats.svg` and other card SVGs — safe placeholders until the first refresh
- `.github/workflows/update-profile-assets.yml` — refreshes the GitHub stats cards and stores the SVGs in your repository
- `README-INSERT.md` — ready-to-paste README sections using local asset paths

## Install it

1. Download and extract this ZIP.
2. Upload the **`assets` folder** to the root of your GitHub profile repository.
3. Upload the **`.github/workflows/update-profile-assets.yml`** file, keeping its exact folder path.
4. In your repository, open **Settings → Actions → General → Workflow permissions**.
5. Select **Read and write permissions**, then save.
6. Open the **Actions** tab → **Update GitHub Profile Assets** → **Run workflow**.
7. Wait for the workflow to finish. It replaces the six placeholder cards with locally stored SVG cards when their providers respond successfully.
8. Copy the content of `README-INSERT.md` into your profile `README.md` (or copy only the sections you want), then commit.

## Important

- Keep `README.md` and the `assets` folder at the same repository root.
- Keep the workflow path exactly as `.github/workflows/update-profile-assets.yml`.
- The custom banner, GIFs, stack graphic, divider and footer are local assets. They do not need an external image host.
- GitHub stats are generated by third-party services. The workflow downloads their SVG output into `assets/`, so the README displays repository-hosted copies. If a provider is temporarily unavailable, the previous card or placeholder is kept.
- The cards update only when the workflow succeeds. Scheduled refresh is every 12 hours; you can also run it manually.
- Public GitHub profile data is used. `count_private=false` is intentional; private contribution details are not included.
- GitHub may take a short time to refresh the README image cache after a commit.

## Troubleshooting

- If the workflow is missing from Actions, check that the workflow file is under `.github/workflows/`.
- If the workflow cannot push, check **Workflow permissions → Read and write permissions**.
- If one card remains a placeholder, its external provider did not return valid SVG during that run. Re-run later or open the provider URL in a browser to test it.
- If an image is broken, verify the filename and capitalization. GitHub paths are case-sensitive.
